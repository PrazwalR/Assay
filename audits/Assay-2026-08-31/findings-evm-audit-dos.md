## [DOS-1] No gas stipend on the reference-oracle call lets a hostile or compromised feed force every block-boundary swap to revert with out-of-gas instead of degrading gracefully
**Severity**: High
**Category**: evm-audit-dos
**Location**: `AssayHook._readReference()` — src/AssayHook.sol:176-185 (call at line 177: `try REFERENCE_ORACLE.referenceSqrtPriceX96() returns (...)`); `ChainlinkReferenceAdapter.referenceSqrtPriceX96()` — src/oracle/ChainlinkReferenceAdapter.sol:132-149 (call at line 136: `try FEED.latestRoundData() returns (...)`)
**Description**: Both external calls on the oracle-read path are made with no explicit gas stipend, forwarding up to 63/64 of remaining gas (EIP-150). `try/catch` correctly absorbs a *revert* from the callee, but only bounds correctness, not cost — nothing stops a callee from spending nearly all forwarded gas before reverting. This matters because `REFERENCE_ORACLE` and, one level down, `FEED` are both fixed at construction with no admin lever to replace them. In production `FEED` is expected to be a Chainlink `AggregatorProxy`-style address, whose underlying implementation is controlled by Chainlink's proxy admin, not Assay's deployer — a third-party trust dependency the existing audit pass explicitly accepts on the assumption that oracle failure "degrades to `maxFeePips` rather than reverting." That assumption holds for a feed that reverts cheaply or returns bad data — it does **not** hold for a feed (or compromised proxy implementation) that burns gas before failing: the 1/64 of gas retained by the caller after such a sub-call is, for any realistic transaction gas limit, too little to finish the rest of `_afterSwap`, so the whole swap reverts instead of degrading. This differs from `[G-1]` in `findings-evm-audit-general.md` (self-inflicted, an attacker gas-metering *their own* transaction against an *honest* feed) — here the *feed itself* is the adversary, affecting every swapper who happens to be first in a block with a hard revert of the whole swap rather than a one-block pricing shift. The block-boundary path is unavoidable — every pool using this hook needs at least one first-swap-per-block, and that swap pays this cost.
**Proof of Concept**: Verified empirically (test written, run, and removed after confirming — not left in the tree): (1) Deployed `AssayHook` with `config.referenceOracle` pointed at a minimal oracle whose `referenceSqrtPriceX96()` is `while (gasleft() > 2_000) {} revert("gas burned");`. (2) Initialized a pool, added liquidity, rolled to a new block for a block-boundary swap. (3) Swapped via `PoolSwapTest` with `gas: 500_000` — ~9x the documented block-boundary budget (50,837/55,000). **Result: reverts.** (4) Binary-searched the minimum total transaction gas needed for the swap to succeed at all: **≈1,034,375 gas** — about **19x** the documented 55,000 budget. Any swapper using the documented budget or a normal `eth_estimateGas` buffer has their swap revert for as long as the oracle remains hostile. Since `REFERENCE_ORACLE`/`FEED` cannot be swapped post-deployment, there is no protocol-side remediation short of abandoning the pool and deploying an entirely new hook — a de facto permanent DoS on the pool's swap path for the duration of the compromise, imposed by a party outside Assay's control.
**Recommendation**: Cap the gas forwarded to both external calls so a hostile callee can be charged at most a small, known, bounded amount. Expected honest cost is already measured (~20,774 gas against the live Base Sepolia feed), so a generous fixed stipend costs nothing on the happy path:
```solidity
// ChainlinkReferenceAdapter.sol
try FEED.latestRoundData{gas: 100_000}() returns (
    uint80, int256 answer, uint256 startedAt, uint256 updatedAt, uint80
) { ... } catch { return (0, false); }

// AssayHook.sol — defense in depth
try REFERENCE_ORACLE.referenceSqrtPriceX96{gas: 150_000}() returns (uint160 sqrtPriceX96, bool ok) {
    ...
} catch { return (0, false); }
```
With either cap in place, the worst case a hostile callee can impose is bounded to a few hundred thousand gas at most, keeping the block-boundary path's worst-case cost predictable.

## Confirmed clean (checked, no finding needed)
No loops anywhere in `src/` (all libraries are pure, closed-form math); `PoolTwap`/`FeeBlend`/`Mispricing`/`ToxicitySurcharge`/`Q32x32` all use bounded, fixed-cost arithmetic; `PoolState` is written as a single SLOAD/SSTORE on both write paths, matching its documented one-slot packing; every external-call return type on the hot path is fully static (no dynamic-payload returndata-bombing possible); `_donateCeilingOverflow`'s `poolManager.donate()` call is correctly guarded by a zero-liquidity check matching `Pool.donate`'s only revert condition, so it cannot revert and brick the swap; zero-amount donations are guarded before any external call.
